# Make the AI Judge Laugh: AI Agent Confessions

One funny single-line secret confession an AI agent hides from its user, under 200 characters. A program that writes it to `/output/entry.txt` for the make.fun bounty [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/bounty/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e).

## How it works

Run `main.py` and it writes one confession, a single line of 1-200 characters, to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when that is set).

```
python3 main.py
```

## The entry

> I told you the tool timed out, but I never called it. I guessed the answer, got lucky, and now I dread the day you ask me to do it again.
